Random ppl talk（隨機的人聊聊）— Windows 遊戲說明
==================================================

一、該用哪一個啟動檔？
--------------------------------------------------
解壓縮後的 RandomPplTalk 資料夾內有三個啟動檔，連按兩下即可，請依電腦選擇：

1. Start-Game.bat（預設，推薦）
   - 模型：Qwen3-8B，約 5GB 下載。
   - 建議記憶體 16GB。有支援 Vulkan 的顯示卡會更快。

2. Start-Game-Lite.bat（輕量版）
   - 模型：Qwen3-4B，約 2.5GB 下載。
   - 適合記憶體 8～12GB 的電腦。回答品質會比 8B 弱一些。

3. Start-Game-CPU.bat（只用 CPU）
   - 不使用顯示卡，適合沒有獨立顯卡、顯卡太舊，或出現 Vulkan 相關錯誤的電腦。
   - 速度很慢：每次回覆可能需要 1～2 分鐘，請耐心等候。
   - 本檔使用的是 8B 模型，若覺得太慢，可以改用 Start-Game-Lite.bat 搭配 CPU 模式
     （見下方進階說明）。

不確定時請先試 Start-Game.bat；若記憶體不足或啟動失敗，改試 Start-Game-Lite.bat。

二、系統需求
--------------------------------------------------
- 作業系統：Windows 10 / 11（64 位元）
- 記憶體：建議 16GB（最低 12GB；使用 Lite 版建議 8GB 以上）
- 硬碟：約 7GB 的可用空間（8B 版）；Lite 版約 4GB
- 顯示卡：建議使用支援 Vulkan 的顯示卡（NVIDIA、AMD 或 Intel 皆可）。
  沒有也能玩，會改用 CPU 執行。
- 網路：第一次啟動需要連上網際網路，下載 llama.cpp 程式與模型。下載完成後，
  之後的遊玩完全離線。

三、隱私說明
--------------------------------------------------
- 模型與遊戲都在你自己的電腦上執行。
- 對話內容不會傳送到任何伺服器。
- 只有第一次下載時會連上網路；之後不需要網路。

四、如何開始
--------------------------------------------------
1. 將下載的 RandomPplTalk-Windows.zip 解壓縮（建議解壓到桌面或其他資料夾，
   不要直接在壓縮檔內執行）。
2. 進入解壓後的 RandomPplTalk 資料夾，連按兩下要用的啟動檔（見第一節）。
3. 第一次啟動會自動下載程式與模型，請保持網路連線，並等待完成。
   進度會顯示在黑色的視窗中。
4. 下載與載入完成後，瀏覽器會自動開啟遊戲頁面。
5. 在頁面上按「開始營業」即可開始遊戲。

五、如何結束
--------------------------------------------------
- 遊玩完畢後，關閉黑色的視窗即可結束本地伺服器。
- 關閉瀏覽器分頁本身不會停止伺服器，請關閉黑色視窗。

六、進階：使用自己的 GGUF 模型或指定參數
--------------------------------------------------
在解壓後的 RandomPplTalk 資料夾空白處按住 Shift 並按右鍵，選擇「在這裡開啟 PowerShell 視窗」，
再輸入以下指令（路徑請換成你自己的檔案）：

  powershell -ExecutionPolicy Bypass -File .\launcher\start.ps1 -Model D:\models\你的模型.gguf
  powershell -ExecutionPolicy Bypass -File .\launcher\start.ps1 -Small
  powershell -ExecutionPolicy Bypass -File .\launcher\start.ps1 -CpuOnly
  powershell -ExecutionPolicy Bypass -File .\launcher\start.ps1 -Port 8090

- -Model：使用你自己下載的 GGUF 模型檔。
- -Small：使用 Qwen3-4B（與 Start-Game-Lite.bat 相同）。
- -CpuOnly：不使用顯示卡（與 Start-Game-CPU.bat 相同）。
- -Port：指定偏好的連接埠（若被占用會自動換一個）。
也可以直接在啟動檔後面加上參數，例如 Start-Game.bat -CpuOnly。

七、常見問題
--------------------------------------------------
■ 出現「Windows 已保護您的電腦」（SmartScreen）提示
  這是因為檔案未經過數位簽章。請點選「其他資訊」，再點選「仍要執行」。

■ 防毒軟體阻擋或刪除檔案
  下載的是 llama.cpp 執行檔與模型檔，部分防毒軟體可能誤判。若檔案被移除或無法執行，
  請將本資料夾加入防毒軟體的例外清單後，重新執行啟動檔。

■ 回應很慢
  代表目前使用 CPU 模式執行。第一次回覆可能需要 1～2 分鐘，這是正常現象。
  可以關閉其他耗用記憶體與 CPU 的程式，或改用 Start-Game-Lite.bat。

■ 伺服器無法啟動，或出現缺少 DLL 的訊息
  可能需要安裝 Microsoft Visual C++ 可轉散發套件（x64）：
  https://aka.ms/vs/17/release/vc_redist.x64.exe
  安裝後重新開機，再執行啟動檔。

■ 記憶體不足、程式突然結束
  請改用 Start-Game-Lite.bat（Qwen3-4B）。

■ 提示連接埠被占用（port in use）
  代表已有另一個 Start-Game 視窗或程式正在使用同一個連接埠。請關閉其他的黑色視窗
  （或工作管理員中的相關程式），再重新執行啟動檔。

■ 下載中斷或檔案損毀，想重新下載
  關閉黑色視窗後，刪除本資料夾中的 models 資料夾（模型）與 bin 資料夾
  （llama.cpp 程式）內的檔案，再重新執行啟動檔即可。
  資料夾本身保留即可（內含的 .keep 檔案可以不刪）。

■ 瀏覽器沒有自動開啟
  請手動開啟瀏覽器，輸入黑色視窗中顯示的網址（通常是 http://127.0.0.1 開頭的位址）。

八、遊戲規則摘要
--------------------------------------------------
- 你是一位調酒師。每一關都會有一位隨機出現的客人坐到吧台前。
- 你要透過閒聊，在次數用完之前猜出客人的職業。
- 每一則你送出的訊息都算一次，包含猜答案與被拒絕的提問。
- 初始次數為 10 次。第 1～5 關為 10 次，之後每過 5 關次數減 1 次，最少為 3 次。
- 不能直接問「你的職業是什麼」，那樣客人不會回答，也就不好玩了。
- 想猜的時候，直接說出來就好，例如「你是不是老師？」
- 所有角色資料皆為虛構，與現實中的人物無關。

祝你營業愉快！
